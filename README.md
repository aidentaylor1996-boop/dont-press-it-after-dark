# DON'T PRESS IT: AFTER DARK

A static, host-operated TV-style game show designed for screen sharing during TikTok LIVE.

## What it includes

- Eight-player setup with local player memory
- Mystery boxes with independent ownership and hidden content
- Multi-stage game flow: boxes, first choice, challenge room, secret missions, danger, chaos, Black Box, final three, last choice, and final reveal
- Host mode and a clean Live Display mode
- Questions, missions, chaos events, scoring, elimination, powers, undo, timers, and replay
- Demo mode with Alex, Jordan, Taylor, Sam, Charlie, Morgan, Jamie, and Riley
- Browser-local save/resume and game history
- Full-screen support
- Prize/entry planning calculator with no payment processing
- Offline-friendly static HTML application

## Run locally

Open `index.html` in a modern browser. No Node, npm, server, database, account, API key, or build process is required.

## Enable GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and the repository root.
5. Save and open the generated Pages URL.

The site uses relative paths and is compatible with GitHub Pages.

## Host workflow

1. Start a new game or choose Demo Mode.
2. Enter exactly eight non-blank player names.
3. Use the stage briefing and Host Help text to run the show.
4. Select a player, choose boxes, reveal outcomes, run questions and missions, and apply score decisions.
5. Use **Enter Live Display** when screen-sharing. Return to Host Mode whenever controls are needed.
6. Use **Play Again — Same Players** after a completed game for fresh randomized content.

## Private information

Private missions and peeks use an on-screen cover-your-eyes flow. The app does not connect to TikTok, Snapchat, messaging, or private accounts. Information is stored locally in the browser only.

## Local storage and reset

The browser stores active games, settings, recent player names, game history, and tutorial state in `localStorage`. Use the Settings controls to reset local data. Clearing site data in the browser also removes saved games and player memory.

## Prize / entry planning

The planning calculator is informational only. It does not process TikTok Coins, gifts, payments, withdrawals, or payouts, and it does not assign a cash value to platform items. Confirm platform rules and applicable legal requirements before using paid entry or prizes.
